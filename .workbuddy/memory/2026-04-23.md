## juice-cli 功能更新

### 配置加载逻辑重构
- 配置优先级（低→高）：CLI 默认 < 用户目录 < 优先配置
- 默认配置统一在 defaults/juice.yaml
- -c 指定 和 输入文件同级目录 互斥

### 右键菜单管理
- npm install：自动注册右键菜单（postinstall hook）
- npm uninstall：自动卸载右键菜单（preuninstall hook）
- 手动命令：`juice --install` / `juice --uninstall`

## juice-cli 新增配置项

- preservePseudos: true 保留伪选择器规则
- insertPreservedExtraCss: true 保留 CSS 插入位置
- preservedSelectors 配置项（示例：.gmail-, #outlook-）
- inlinePseudoElements: true 启用伪元素内联
