# 2026-04-23

## juicu-cli 工具开发完成

完成了 `juicu-cli` 命令行工具的完整开发，功能：
- 使用 `juice` 库将 HTML 邮件模板中的 CSS 全部内联，兼容 Gmail/Outlook/Apple Mail 等
- 使用 `mustache` 支持 `{{变量名}}` 模板变量替换，变量通过 `juice.yaml` 配置文件定义
- 配置文件自动查找：命令行 `-c` 指定 > 当前目录 `juice.yaml/yml` > 用户主目录 `juice.yaml/yml`
- 支持 Windows 右键菜单注册（`juice --register`，需管理员权限）
- 依赖：`juice`, `mustache`, `commander`, `js-yaml`, `chalk`, `ora`

工具结构：
- `bin/juice.js`：CLI 入口
- `src/index.js`：核心处理逻辑
- `src/context-menu.js`：Windows 右键菜单注册
- `examples/juice.yaml`：配置文件示例
- `examples/template.html`：HTML 邮件模板示例

端对端测试通过：style 标签移除、CSS 内联、Mustache 变量替换均正常。
